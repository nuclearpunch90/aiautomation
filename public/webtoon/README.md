# 웹툰 이미지 업로드 가이드

이 폴더에 웹툰 이미지를 업로드하세요.

## 📁 파일명 규칙

### Before (자동화 도입 전) - 3개
- `before-1.png` - 첫 번째 패널 (예: 고객 문의에 지친 사장님)
- `before-2.png` - 두 번째 패널 (예: 데이터 입력 작업)
- `before-3.png` - 세 번째 패널 (예: 직원들 지쳐가는 모습)

### After (자동화 도입 후) - 3개
- `after-1.png` - 첫 번째 패널 (예: AI가 자동 응대)
- `after-2.png` - 두 번째 패널 (예: 자동화로 시간 절약)
- `after-3.png` - 세 번째 패널 (예: 행복한 사장님과 직원들)

## 🎨 이미지 권장 사양

- **파일 형식**: PNG, JPG, WebP
- **권장 크기**:
  - 가로: 800px ~ 1200px
  - 세로: 자유 (비율 유지)
- **파일 크기**: 각 이미지당 2MB 이하 권장
- **비율**: 웹툰 컷 형태 (세로가 긴 형태 추천)

## 📝 사용 예시

```
public/webtoon/
├── before-1.png   ← AI 도입 전 첫 번째 컷
├── before-2.png   ← AI 도입 전 두 번째 컷
├── before-3.png   ← AI 도입 전 세 번째 컷
├── after-1.png    ← AI 도입 후 첫 번째 컷
├── after-2.png    ← AI 도입 후 두 번째 컷
└── after-3.png    ← AI 도입 후 세 번째 컷
```

## ✅ 확인 사항

1. 파일명이 정확히 일치하는지 확인 (대소문자 구분)
2. 이미지가 깨지지 않았는지 확인
3. 파일 크기가 너무 크지 않은지 확인

## 💡 팁

- 웹툰 스타일의 말풍선과 텍스트는 이미지에 포함시키세요
- 밝고 읽기 쉬운 이미지를 사용하세요
- 모바일에서도 잘 보이도록 텍스트 크기를 충분히 크게 만드세요
